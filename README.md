# Getting Started with YOLOv11

This repository provides a beginner-friendly introduction to **YOLOv11 (You Only Look Once)** for real-time object detection.  
It covers installation, model loading, inference on images/videos, and basic understanding of YOLO workflows using Python.

## 🚀 Features
- Introduction to YOLOv11 architecture
- Running object detection on images and videos
- Pretrained model inference
- Easy-to-follow Python examples
- GPU and CPU support

## 🛠️ Tech Stack
- Python
- PyTorch
- YOLOv11
- OpenCV
- NumPy
